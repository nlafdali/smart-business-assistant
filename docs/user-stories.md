# 📘 User Stories – Smart Business Assistant

## 🎯 Ziel

Support-Mitarbeiter sollen Anfragen schneller bearbeiten können.

---

## 🟢 Core Features

### US-1: Anfrage erstellen

Als Support-Mitarbeiter
möchte ich eine Anfrage speichern
damit ich sie später bearbeiten kann.

---

### US-2: Anfragen anzeigen

Als Support-Mitarbeiter
möchte ich alle Anfragen sehen
damit ich den Überblick behalte.

---

## 🟡 Struktur

### US-3: Kategorie setzen

Als Support-Mitarbeiter
möchte ich Anfragen kategorisieren
damit ich sie schneller sortieren kann.

---

### US-4: Priorität setzen

Als Support-Mitarbeiter
möchte ich Prioritäten festlegen
damit wichtige Fälle zuerst bearbeitet werden.

---

## 🔵 AI Feature

### US-5: Automatische Analyse

Als Support-Mitarbeiter
möchte ich automatisch analysierte Anfragen sehen
damit ich Zeit spare.

---

### US-6: Zusammenfassung

Als Support-Mitarbeiter
möchte ich eine Zusammenfassung der Anfrage
damit ich schneller entscheiden kann.
