# smart-business-assistant
Smart Business Assistant 🤖
📌 Beschreibung

Ein Backend-System auf Basis von Spring Boot, das Geschäftsanforderungen verarbeitet und mithilfe von KI erweitert.

🚀 Funktionen
Erstellen und Verwalten von Anfragen
Kategorisierung und Priorisierung
KI-gestützte Analyse (geplant)
🛠️ Technologien
Java
Spring Boot
Spring Data JPA
Maven
H2-Datenbank
📈 Status

🚧 In development
